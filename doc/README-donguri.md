# どんぐり

## 概要

5chのどんぐり基地(https://donguri.5ch.net/)に対応するものです。

ブラウザでどんぐりシステムにGmailで登録した警備員●のアカウントをrep2に設定してログインすることにより、rep2から警備員●として書き込み出来るようになります。

また、UPLIFTのアカウントを使ってどんぐりシステムにログインすることにより、ハンターとして書き込みが可能です。

おまけでrep2で自動ログインされている警備員○をどんぐり基地で見る方法も用意しましたが、かなり面倒な手順です。

## 設定

「設定管理 > ユーザ設定編集」の「rep2基本設定 > donguri」のdonguri_useを「する」に設定するとどんぐりの状態やどんぐり基地、どんぐり対応へのリンクが表示されるようになります。

### 警備員●として書き込みをする

donguri_methodを0に設定し、donguri_userとdonguri_passwordにどんぐりシステムに登録したGmailアドレスとパスワードを設定してください。

パスワードはGmailやGoogleのパスワードではなくてどんぐりシステムの方です。

### ハンターとして書き込みをする

donguri_methodを1に設定し、「ログイン管理 > 2chログイン管理」にUPLIFTのアカウントを登録してください。

なお、2chログイン中かどうかに関係なく、どんぐりシステムへログインしてハンターのどんぐり(acorn)を受け取ることが可能なようです。

## 使い方

* PC：板一覧の上にどんぐり(名前やID)が表示されます。また、どんぐり基地へのリンクが表示されます
* スマホ：ログイン情報にどんぐり(名前やID)が表示されます。また、どんぐり基地へのリンクが表示されます
* 携帯：ログイン/ログアウトは出来ませんが、PCやスマホでログインした場合、ログイン状態は維持されています
* PCとスマホ：スマートポップアップメニュー(SPM:レス番号を選択すると表示されるメニュー)にどんぐり大砲が表示されます

## 説明

表示は状態によって以下のように変わります。

| 状態           | どんぐり(acorn) | 説明                                                                            | 表示されるリンク         |
| -------------- | --------------- | ------------------------------------------------------------------------------- | ------------------------ |
| 未確認         | 未確認          | 何かおかしい(Javascriptがオフ?)                                                 | 確認                     |
| どんぐり無し   | 無し            | rep2にacornのクッキーがない状態                                                 | ログイン                 |
| 不正などんぐり | 有り            | どんぐりシステムにどんぐりの確認しようとするとエラーになる状態                  | 確認, ログイン           |
| 警備員○        | 有り            | 自動ログインされている警備員○のどんぐりを持っている状態。名前やIDが表示されます | どんぐり基地, ログイン   |
| 警備員●        | 有り            | Gmailで登録した警備員●にログインした状態。名前やIDが表示されます                | どんぐり基地, ログアウト |
| ハンター       | 有り            | UPLIFTアカウントでハンターにログインした状態。名前やIDが表示されます            | どんぐり基地, ログアウト |

### 表示されるリンクについて

表示されるリンクを選択すると以下のような動作となります。

* 確認：クッキーを確認しどんぐりがあればどんぐりシステムへ確認し表示を更新します

* ログイン：GmailアカウントかUPLIFTアカウントが登録されているときに表示されます。ログインに成功すると警備員● or ハンターになります。**:warning: 警備員○の状態でログインすると自動ログインしているどんぐりをrep2で保持しておく機能はないため、捨てることになります**

* どんぐり基地(警備員○のとき)：別タブでどんぐり基地を表示するための ~~ブックマークレットの用意が必要だったりかなり面倒な~~ 手順の説明が表示されるのでそちらを確認してください。
普通の人は見ただけでそっと閉じることになるでしょう

* どんぐり基地(警備員●のとき)：別タブでどんぐり基地を表示します。
ブラウザでどんぐりシステムにGmailアカウントでログインするとrep2と同じIDが表示されているのを確認できるはずです。

* どんぐり基地(ハンターのとき)：別タブでどんぐり基地を表示します。
ブラウザでどんぐりシステムにUPLIFTアカウントでログインするとrep2と同じIDが表示されているのを確認できるはずです。

* ログアウト：ログアウトするとどんぐり無しの状態になります

### スマートポップメニューのどんぐり大砲について

選択すると確認ダイアログ後、どんぐり基地から大砲を撃ちます。
どんぐり大砲はrep2でなくブラウザのどんぐりを使用するため、どんぐりシステムにUPLIFTアカウントでログインする必要しておく必要があります。
(ログインしていないとUPLIFTのログイン画面へ飛ばされます)

## TIPS

不正などんぐりの状態で5chに書き込みしても復帰しない場合、「設定管理」の「履歴・キャッシュの削除」でCookieを削除するしかないかも。

警備員●やハンターでログインした状態でdonguri_useを「しない」した場合、どんぐりの表示はなくなりますが、クッキー内のどんぐりはそのまま警備員●やハンターです。

proxyを使用していてproxy側でクッキーを保持する機能が有効になっている場合、想定外の動作となる恐れがあります。

## 既知の問題

自動ログインされている警備員○のどんぐりのクッキーは有効期限がありますが(5日後の朝9時？)、rep2はクッキーの有効期限を正しく管理出来ていません(1970年のクッキーが来て捨てるケースは対応出来ています)。

よって、本来であればどんぐりの有効期限が切れた状態で書き込みするとどんぐり無しで書き込みをして自動ログインし直す動作となるのが期待値ですが、期限切れのどんぐりを使うことになるので書き込みエラーになりそうです。

書き込みのエラーが続いて復帰出来ないときは設定管理でCookieの削除を実施してください。

なお、このクッキーの有効期限の管理が出来ていない件は5chに限らずどの掲示板でも同様に発生します。
