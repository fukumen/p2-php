# 5chログインについて

## 概要

「ログイン管理 > 2chログイン管理」にUPLIFTのアカウントを登録しログインすることで5chにログインすることが出来ます。
また、UPLIFTのアカウントを設定しておくことで[どんぐりシステム](README-donguri.md)へのログインにも使用します。

ログイン方法は新方式の「uplift」と従来方式「tora3」の2つがあります。2つありますがログインできるのは片方のみとしています。

## UPLIFTによる5chログイン

UPLIFTへログインしてクッキーのsidを取得し5chへの書き込み時に使用します。

5ch書き込み時にsidの期限が切れていると自動的にUPLIFTへ再ログインしてsidを再取得します。tora3のように書き込み時にsidを使用する/しないの選択は用意していません。

sidの期限はクッキーの期限を指しています。現状では23時間が指定されているようです。

また、upliftの場合、ログイン中は2chログイン管理で有効期限を表示をします。

## tora3による5chログイン

従来どおりの動作をします。

tora3へログインしてパラメータのsidを取得し5chへの書き込み時に使用します。upliftとは違い「2ch●IDの使用」がチェックされているときのみです。

5ch書き込み時に「2ch●IDの使用」がチェックされてログインから24時間経過していると自動的にtora3へ再ログインしてsidを再取得します。

あと、disp_ronin_expirationによる有効期限表示は機能していないので(無駄な通信が発生するだけで実害はなさそうに見えますが)初期値を「しない」に変更しました。

## 自動ログインについて

2chログイン管理で「自動ログインする」と「しない」がありますが、
PCでrep2のタイトル表示（ログイン直後にバージョンが表示される画面）が表示されるタイミングで毎回ログインをするかしないかの設定です。

スマホにはタイトル表示が存在しないのでPCだけ意味のある設定のようです。
(トップ画面で毎回ログインするのも変ですし)

自動ログインの設定に関係なく、5ch書き込み時にsidが期限切れの場合は更新します。

## TIPS

5chログインとどんぐりの組み合わせ(警備員○/警備員●/ハンター)は、通常のブラウザであればどの組み合わせでも出来るはずなのでrep2としても特に制限を設けていません。

書き込み時に見慣れないエラーが起きた場合、設定管理でCookieを消して5chログインやどんぐりのログインもし直すと復旧するかもしれません。

なお、UPLIFTのsidはクッキーですが、rep2ではどんぐりと違い別ファイルで管理をしているため、Cookieを消してもsidは消えません。5chログアウトすると消えます。
